# MVP Scope

## Product Goal

Build a mobile-first, web-mirrored healthcare operations platform where staff, managers, and super admins can run daily work through ticketed, auditable workflows.

The MVP is not a full healthcare EHR, payroll processor, accounting system, telephony platform, or autonomous AI system. It is the operational control layer that connects users, tasks, approvals, documents, inventory, incidents, and reporting.

## MVP Modules

1. Authentication, roles, permissions, and audit foundation.
2. Universal ticket system for operational tasks and approvals.
3. User and entity registry for people, suppliers, assets, inventory, AI agents, and patient references.
4. Human and non-human onboarding workflows.
5. Contracts, consent, policy acknowledgements, documents, and training records.
6. Super admin dashboard with drilldowns and operational reports.
7. Roster, leave, attendance, shift handover, timesheet, and payroll-readiness workflows.
8. Inventory, procurement, barcode/QR scanning, stock movement, delivery, expiry, and reorder workflows.
9. Incident, escalation, emergency, privacy breach, and patient communication workflows.
10. AI/voice pilot with action logging, draft creation, and human review.
11. Next.js web UI and Expo mobile UI built in parallel with the backend.

## MVP Role Set

- Super Admin
- Clinic Manager / Practice Manager
- HR / Payroll Admin
- Finance / Accounts User
- Compliance Officer
- Receptionist
- Doctor / Practitioner
- Nurse / Clinical Assistant
- Pharmacist / Medication Manager
- Inventory / Procurement User
- Supplier / Vendor
- Contractor / Service Provider
- AI Agent

Patients are represented in MVP as minimal operational records and communication targets. A patient self-service portal is deferred.

## Launch Workflows

The MVP is launchable when these workflows work end to end:

1. Super admin signs in, reviews dashboard, drills into a user and ticket, and exports a report.
2. Receptionist signs in on mobile, sees tasks, creates a ticket, updates work, scans stock, submits handover, and requests leave.
3. Manager reviews a completed ticket, requests correction or approves it for payroll readiness, and adds appraisal feedback.
4. HR assigns onboarding steps, documents, contracts, and training to a staff member.
5. Inventory user scans stock or delivery, creates a stock movement, and triggers a reorder or issue ticket.
6. Compliance officer reviews training, contract expiry, incidents, privacy acknowledgements, and AI activity.
7. AI assistant creates draft ticket/suggestion records that require human review before sensitive action.

## Deferred Scope

- Full clinical EHR and clinical decision support.
- Direct My Health Record integration.
- Patient self-service portal and telehealth portal.
- Banking, payroll disbursement, card payments, and supplier payment execution.
- Advanced accounting/BAS/GST automation beyond exports and readiness records.
- Autonomous AI approvals or clinical actions.
- Offline-first mobile synchronization.
- Predictive staffing, burnout alerts, anomaly/fraud detection, and smart reorder forecasting.
- Visitor badge printing and advanced OCR.
- Franchise, multi-entity, and advanced multi-branch operations.
- Deep integrations with booking, telephony, medical, payroll, accounting, or banking systems.

## MVP Acceptance Criteria

- Every major workflow creates or links to a ticket.
- Every sensitive mutation creates an audit event.
- Every user-facing backend slice has matching web UI and mobile UI where the workflow is mobile-relevant.
- Role-scoped users cannot view or mutate forbidden records.
- Payroll readiness can be reviewed and exported but does not execute payments.
- Patient records store only the minimum operational data approved by the patient-data boundary.
- AI actions are visible, logged, and human-reviewable.
- Reports are permission-scoped and exportable for operational review.

## Phase 2 Starting Assumptions

- Backend stack: Python 3.13, Django 5.2 LTS, Django REST Framework, PostgreSQL, Celery, Redis, drf-spectacular, pytest, Docker.
- Web stack: Next.js, React, TypeScript, Tailwind CSS, shadcn/ui, TanStack Query, React Hook Form, Zod.
- Mobile stack: Expo React Native, TypeScript, Expo Router, NativeWind, Expo Camera.
- API contract: DRF OpenAPI schema generated by drf-spectacular and consumed by generated TypeScript clients.
